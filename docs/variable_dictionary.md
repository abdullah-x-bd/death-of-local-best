# Variable dictionary

Working dictionary. Names may change before the first frozen analytic dataset.

| Variable | Level | Definition | Status |
|---|---|---|---|
| year | time | calendar year | planned |
| area_id | geography | harmonized local labor-market identifier | unresolved |
| occupation_id | occupation | harmonized occupation identifier | unresolved |
| broadband | area-year | primary broadband availability measure | unresolved |
| digital_tradability | occupation | predetermined continuous digital-tradability score | unresolved |
| occ_present | area-occ-year | indicator that occupation is observed above reliability threshold | primary candidate |
| occ_emp_share | area-occ-year | occupation employment / total local employment | primary candidate |
| real_median_earnings | area-occ-year | weighted median real earnings | primary candidate |
| occ_employment | area-occ-year | weighted employment count | secondary |
| self_emp_share | area-occ-year | weighted self-employment share | secondary |
| entrant_share | area-occ-year | share of occupation workers in prespecified young-entry age band | secondary |
| p90_p50 | area-occ-year | P90 earnings / median earnings | secondary |
| p50_p10 | area-occ-year | median earnings / P10 earnings | secondary |
| migration_rate | area-occ-year | prespecified migration measure | secondary |
| ai_exposure | occupation | published or reproducible occupational AI exposure | Wave 2 |
