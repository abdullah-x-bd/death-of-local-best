# Historical O*NET measurement protocol

O*NET 4.0 is the primary O*NET baseline for pre-treatment occupational descriptors because it is the final analyst-only database and provides the same descriptor range across more than 900 occupations.

O*NET 5.0 is retained as a secondary baseline and transition check.

## Stage 3 rule

The first pass produces an inventory and a blind candidate descriptor sheet only.

No occupation receives a market-shelter score at this stage.

No descriptor may be selected because it produces a stronger labor-market coefficient.

Candidate items are retrieved using words tied to the written theory, such as physical proximity, face-to-face contact, computers, customers, public interaction, machinery and physical handling.

Before a treatment-effect regression is run, the project must freeze:

1. which O*NET items map to physical-presence dependence;
2. which items map to relational/accountability dependence;
3. which items are merely validation measures rather than components;
4. scale transformations and missing-data treatment;
5. whether components remain separate or enter a secondary equal-weight index;
6. the occupation crosswalk from O*NET-SOC to the IPUMS occupation coding.

The primary analysis should keep theoretically distinct dimensions separate wherever feasible. A composite market-shelter index is secondary and must use pre-specified, outcome-independent weights.
